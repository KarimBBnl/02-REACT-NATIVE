# Ejercicio 01 - Mi primera pantalla

## Qué he aprendido
- `View` sirve para organizar y agrupar elementos de la interfaz.
- `Text` sirve para mostrar texto en pantalla.
- `StyleSheet` permite definir los estilos de forma ordenada y reutilizable.
- `flex: 1`, `justifyContent` y `alignItems` ayudan a colocar el contenido.

## Respuesta a la pregunta de comprensión
Explica con tus palabras la diferencia entre el componente `View` y el componente `Text`.

Respuesta:
`View` es un contenedor que permite agrupar componentes y aplicarles una distribución o unos estilos. `Text` es el componente destinado a mostrar texto. Para construir una pantalla normalmente se utiliza una `View` como estructura y uno o varios `Text` dentro de ella.
